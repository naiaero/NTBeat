# 🎵 NTBeat

**NTBeat** adalah sebuah platform terpusat yang berfungsi untuk mengelola, menyebarkan, dan memfasilitasi akses informasi terkait konser. Dengan adanya sistem ini, alur informasi konser di Nusa Tenggara Barat menjadi lebih cepat, akurat, transparan, dan mudah diakses oleh masyarakat luas.

## 🎭 NTBeat Website Actor

Sistem NTBeat membagi hak akses ke dalam dua jenis pengguna utama:
1. **👑 Administrator:** Mengelola data acara, menambahkan konser baru, dan memonitor arsip penyelenggaraan.
2. **👤 Customer:** Mengakses daftar konser, melihat detail acara, dan mengelola tiket pribadi.
